# Portafolio

```
portafolio/
├── index.html      Página principal (debe quedar en la raíz para GitHub Pages)
├── css/styles.css  Estilos
├── js/main.js      Scripts
└── img/            Imágenes (favicon.svg incluido)
```

## Antes de publicar
- Reemplaza "Tu Nombre" en `index.html`.
- Completa las tecnologías de Sicosi y el texto de tu práctica (hay comentarios en el HTML).
- Cambia los enlaces de correo, GitHub y LinkedIn.

## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta a un repositorio público.
2. En *Settings → Pages* elige la rama principal y la carpeta raíz.
